# 智能复盘助手 - 邮箱验证功能部署指南

> 本文档记录了完整的邮箱验证功能实现过程，包括工具介绍、操作步骤和故障排查。
> 
> 创建时间：2026年2月7日
> 适用版本：智能复盘助手 v1.0+

---

## 一、技术架构概览

```
用户浏览器 → IIS前端网站 → Node.js邮件服务 → SendCloud API → 用户邮箱
```

### 1.1 核心组件

| 组件 | 用途 | 部署位置 |
|------|------|----------|
| **SendCloud** | 国内邮件发送服务，提供稳定可靠的邮件发送API | 第三方云服务 |
| **Node.js** | 后端运行环境，搭建邮件转发服务器 | 云服务器 |
| **pm2** | 进程管理工具，确保邮件服务后台稳定运行 | 云服务器 |
| **IIS** | Windows Web服务器，托管前端网站 | 云服务器 |
| **Windows防火墙** | 开放3000端口，允许外部访问邮件服务 | 云服务器 |
| **云服务器安全组** | 配置入站规则，开放3000端口 | 云平台控制台 |

### 步骤3：创建邮件模板

**操作对象**：SendCloud控制台 → 邮件发送 → 邮件模板

1. 点击"创建模板"
2. 填写模板信息：
   - **模板名称**：验证码模板
   - **调用名称**：`verify_code_template` ⭐ **重要，代码中要用**
   - **邮件主题**：`【智能复盘助手】您的验证码是：%verify_code%`
   - **邮件类型**：触发邮件

3. 编辑邮件内容（富文本模式）：
```
尊敬的 %name%：

感谢您注册智能复盘助手！

您的邮箱验证码是：%verify_code%

⏰ 验证码有效期为 10 分钟，请尽快完成验证。

如非本人操作，请忽略此邮件。

---
智能复盘助手团队
```

**变量说明**：
- `%name%` - 收件人姓名
- `%verify_code%` - 验证码

4. 点击"保存"

---

### 步骤4：服务器安装 Node.js

**操作对象**：云服务器（Windows Server）

1. 下载 Node.js 安装包
   - 地址：https://nodejs.org/
   - 选择：Windows 安装程序(.msi)
   - 版本：LTS（长期支持版）

2. 运行安装程序
   - 双击下载的 .msi 文件
   - 一路点击"Next"（保持默认设置）
   - **不要勾选** "Automatically install the necessary tools"
   - 点击"Install"完成安装

3. 验证安装
   - 打开 CMD
   - 输入：`node -v`
   - 应显示版本号，如：`v24.13.0`

---

### 步骤5：配置 Windows 防火墙

**操作对象**：云服务器（Windows防火墙）

**操作方式**：CMD命令行（管理员权限）

```cmd
netsh advfirewall firewall add rule name="NodeJS Email Server" dir=in action=allow protocol=TCP localport=3000
```

**验证命令**：
```cmd
netstat -ano | findstr :3000
```
应显示 LISTENING 状态。

---

### 步骤6：配置云服务器安全组

**操作对象**：云平台控制台（腾讯云/阿里云等）

1. 登录云服务器控制台
2. 找到"安全组"设置
3. 点击"添加规则"
4. 填写规则：
   - **类型**：自定义
   - **来源**：0.0.0.0/0（或指定IP）
   - **协议端口**：TCP:3000
   - **策略**：允许
   - **备注**：邮箱验证服务
5. 点击"确定"保存

---

### 步骤7：使用 pm2 启动邮件服务

**操作对象**：云服务器（CMD命令行）

**前置条件**：已完成步骤4（安装Node.js）

1. 安装 pm2（全局安装）
   ```cmd
   npm install -g pm2
   ```

2. 进入邮件服务目录
   ```cmd
   cd C:\inetpub\wwwroot\Intelligent-Retrospection-Assistant-master\server
   ```

3. 使用 pm2 启动服务
   ```cmd
   pm2 start email-server.js --name "email-server"
   ```

4. 保存配置（开机自启）
   ```cmd
   pm2 save
   pm2 startup
   ```

5. 验证运行状态
   ```cmd
   pm2 list
   ```
   应显示 `email-server` 状态为 `online`

**常用维护命令**：
```cmd
pm2 list                    # 查看服务状态
pm2 logs email-server       # 查看运行日志
pm2 restart email-server    # 重启服务
pm2 stop email-server       # 停止服务
```

2. **修改sendVerificationEmail函数**（约第1022行）
   ```javascript
   function sendVerificationEmail(email, verifyCode) {
       fetch(EMAIL_SERVER_URL, {
           method: 'POST',
           headers: {
               'Content-Type': 'application/json'
           },
           body: JSON.stringify({
               email: email,
               verifyCode: verifyCode
           })
       })
       .then(response => response.json())
       .then(data => {
           if (data.success) {
               alert('验证码已发送至您的邮箱，请查收！');
           } else {
               alert('邮件发送失败：' + data.error);
           }
       })
       .catch(error => {
           alert('邮件服务暂时不可用');      });
   }
   ```

## 五、故障排查

### 问题1：邮件发送失败，提示"Failed to fetch"

**可能原因**：
- 后端服务未启动
- 防火墙未开放3000端口
- 安全组未配置

**解决方案**：
1. 检查服务状态：`pm2 list`
2. 检查防火墙规则
3. 检查安全组配置

---

### 问题2：SendCloud返回"认证失败"

**可能原因**：
- API_USER或API_KEY错误
- API_KEY已过期

**解决方案**：
1. 核对SendCloud控制台中的API_USER
2. 重新生成API_KEY
3. 更新`email-server.js`中的配置

---

### 问题3：邮件发送成功但用户未收到

**可能原因**：
- 邮件进入垃圾箱
- 邮箱服务商拦截

**解决方案**：
1. 检查垃圾箱
2. 将发件人添加到白名单
3. 使用企业邮箱测试

## 六、安全建议

1. **定期更换API_KEY**（建议每3个月）
2. **限制发送频率**（前端已做60秒限制）
3. **监控发送日志**（使用`pm2 logs`查看）
4. **使用HTTPS**（生产环境建议配置SSL证书）
